This project investigates the factors affecting therates of divorce mainly in the UK. All data is from ourworldindata.
main limitation of the divorce data is that the divorce rate is per 1000 people rather than 1000 married people which reduces the validity of the metric post 1982 as the marraige rate started to decrease after 1982. ( https://ourworldindata.org/marriages-and-divorces)
